# Intelligent Cyber Bullying Detection
> **Final-Year B.Sc. Artificial Intelligence and Data Science College Project**  
> Multilingual AI-Powered Real-Time Comment Moderation System (English, Tamil Unicode, Tanglish)

---

## 📌 Project Overview

Online cyberbullying, harassment, and toxic language threaten digital well-being across social platforms. Traditional automated moderation tools struggle with non-English dialects and regional code-switching, frequently failing to flag regional slurs or erroneously censoring benign cultural idioms.

**Intelligent Cyber Bullying Detection** provides a full-stack, real-time machine learning solution capable of processing:
1. **Standard English**
2. **Tamil Unicode script** (`\u0B80` to `\u0BFF`)
3. **Tanglish (Tamil-English phonetic transliteration)**

The system delivers real-time inference in sub-20ms, alerting users with compassionate warning banners before their comments are posted, and immediately blocking severe harassment, threats, and hate speech.

## 🏛 System Architecture & Pipeline

```
[ User Input (English / Tamil / Tanglish) ]
                   │
                   ▼
       [ 1. Text Normalization ]
 (Lowercase, URL strip, Unicode preservation U+0B80-U+0BFF)
                   │
                   ▼
     [ 2. Subword & N-Gram Tokenization ]
                   │
                   ▼
   [ 3. TF-IDF Feature Extraction (n-grams 1-3) ]
                   │
                   ▼
 [ 4. Multiclass Calibrated Probabilistic ML Classifier ]
                   │
                   ▼
      [ 5. Decision & Moderation Engine ]
    ┌──────────────┬──────────────┬──────────────┐
    ▼              ▼              ▼              ▼
  [Safe]       [Bullying]    [Severe Threat]  [Audit Log]
 (Approved)    (Warning)        (Blocked)      (SQLite DB)
```

## 🚀 Key Modules & Capabilities

1. **AI Comment Moderation**:
   - Submits text through the `/api/predict` and `/api/comments` endpoints.
   - Shows live `"AI is analyzing your comment..."` processing state.
   - Outputs confidence score (`92%`) generated by genuine classifier calculations.
   - Respectful UI offering "Edit Comment" and "Cancel" buttons.

2. **Multilingual Dravidian NLP**:
   - Explicitly preserves Tamil Unicode letters without stripping diacritics.
   - Evaluates common Tanglish colloquialisms (e.g., `loosu`, `mooditu po`, `un moonji`, `semma`, `romba nalla`).

3. **Admin Analytics Dashboard**:
   - Stat cards: Total Comments, Safe Comments, Bullying Comments, Blocked Comments, Average Confidence.
   - Interactive SVG Confusion Matrix Heatmap (Safe vs Bullying vs Severe Bullying).
   - Real calculated model evaluation metrics (Accuracy, Precision, Recall, F1-Score).
   - Live stream moderation logs with filters (All, Safe, Bullying, Blocked, Tamil/Tanglish).

4. **Responsible AI Framework**:
   - Algorithmic fairness, transparency, and data privacy disclosures.
   - Analysis of False Positives (over-censorship) and False Negatives (obfuscated insults).
   - Academic disclosure of Tamil/Tanglish dataset constraints.

## 🐍 Training the Machine Learning Model (Python)

To train the Scikit-Learn model locally:

1. Install Python requirements:
```bash
pip install -r requirements.txt
```

2. Run the training script:
```bash
python train_model.py
```

The script will:
- Load the curated dataset from `dataset/cyberbullying_dataset.csv`.
- Clean and normalize text while preserving Tamil Unicode characters (`[\u0B80-\u0BFF]`).
- Perform 80/20 train/test split.
- Extract TF-IDF n-gram features (1 to 3-grams).
- Train the calibrated classifier.
- Compute Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
- Export `model/cyberbullying_model.pkl`, `model/vectorizer.pkl`, and `model/model_metadata.json`.

## 🎓 Viva Questions & Answers for Examiners

**Q1: Why did you choose TF-IDF with n-grams over a simple keyword blocklist?**  
*Answer:* Blocklists fail against morphological variations, negations, and compound sentences. Character/word n-grams with TF-IDF capture contextual word sequences and distinguish between isolated words and actual toxic phrases.

**Q2: How does the system handle Tamil Unicode characters?**  
*Answer:* Standard English regexes (`[^\w\s]`) accidentally strip non-ASCII characters, corrupting Tamil text. Our preprocessor uses Unicode block range preservation `[^\w\s\u0B80-\u0BFF]`, ensuring Tamil letters and vowel modifiers are left intact.

**Q3: What happens when a user submits a bullying comment?**  
*Answer:* The system intercepts the comment before database commit. For moderate bullying, it issues an interactive warning prompt asking the user to self-reflect or edit. For severe threats, it blocks the comment immediately and registers an entry in the `moderation_logs` audit table.
